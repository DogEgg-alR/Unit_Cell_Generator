## 快速开始

1. 双击 `index.html`（推荐 Chrome / Edge / Firefox 新版）。
2. **单文件**：three.js r128 与 OrbitControls 已内嵌进 `index.html`，不依赖任何 CDN、不依赖其它文件，离线双击即可运行。
3. 打开后默认是「简单立方」，3D 与投影图已生成；直接拖动即可旋转。
4. 上方的「晶胞类型」换一个，例如**氯化钠**、**金刚石**、**石墨**，3D 图立即重建。

> 完整文件约 **730 KB**。如果打开后只弹出「3D 显示库没有加载成功」，说明文件不完整（被截断或只下载了几十 KB），重新下载完整版即可。

### 部署到 GitHub Pages

只需要一个文件：

```
Unit_Cell_Generator/
├─ index.html        # 约 730 KB，已内置 three.js，自带全部功能
└─ README.md
```

步骤：

1. 仓库 → `Add file → Upload files`，把 `index.html` 拖进去 → `Commit changes`（或用 `git add index.html && git commit -m "..." && git push`）。
2. 确认 `Settings → Pages` 的 Source 指向 `main` 分支的 `/ (root)`。
3. 等 1–2 分钟，访问 `https://<用户名>.github.io/Unit_Cell_Generator/`，并按 **Ctrl+F5** 强制刷新，排除旧缓存。

> 旧版本里 `index.html` 从 cdnjs / jsdelivr 加载 three.js。国内网络访问这两个 CDN 会被拦（浏览器报 `blocked by CORS policy`、`ERR_FAILED`），随后 `THREE.OrbitControls is not a constructor`，页面就只剩左栏。内置后彻底没有这个依赖，也不需要再传 `libs/` 文件夹。

## 左栏：建模与参数

### 1. 晶胞类型 / 形状

下拉框选择预设结构，切换会载入该结构的标准原子排布，并重置坐标系原点。
描述性文字会提示当前晶系的约束条件（如「立方晶系：a = b = c，α = β = γ = 90°」）。

### 2. 晶胞参数

- **支持字母**：填 `a`、`b`、`c` 表示「按该结构的真实棱长等比缩放」——球的大小按真实晶体学数据换算，晶胞本身仍画成 1 个单位，各结构之间的相对观感一致。
- **支持数字**：填 5.64 之类会按所选单位换算（配合下方的单位下拉框）。
- **单位**：pm / Å / nm（默认）/ µm / cm / m，仅影响「数字参数」的尺寸换算。
- **按晶系自动约束**：立方只需 a；四方（金红石）自动 b = a；六方取六边形棱长 a + 高 c（c 留空时按该结构的理想 c/a 自动补全，石墨 2.73、冰 1.628、镁 1.624）；单斜可改 β；三斜 α、β、γ 全可改，切到三斜会自动填入 80° / 75° / 70° 以免看起来和立方一样。

### 3. 显示模式控制

| 控件 | 作用 |
|---|---|
| **3D 视图 - 空间填充** | 开：原子按真实半径比例（密堆积观感）；关：球棍模型，半径压缩、内部结构更清楚 |
| **投影图 - 空间填充** | 同上，作用于下方投影图 |
| **3D 中显示投影面** | 是否在 3D 里画出条纹透明投影面 |
| **投影图 - 显示晶胞外原子** | 投影图里是否画出跑出晶胞框的原子（石墨、冰等层状结构边界补全后会露在外面）；3D 图始终显示 |
| **投影面颜色 / 透明度** | 取色器选色，滑块 8%–80%，改动立刻反映到 3D 里的投影面 |

> 投影面始终与下方投影图的视角一致，并且**随晶胞一起转动**（它建在场景里，不挂在相机上）。

### 4. 坐标系设置（本工具的特色）

- **显示 xyz 坐标轴**：3D 中的彩色箭头 + 字母精灵（x 橙、y 绿、z 蓝）。
- **每根轴单独指定方向**：X / Y / Z 各自可选「沿 x 轴 (+x) / 反向 (−x) / 沿 y 轴 … / 沿 z 轴 …」。若两根轴撞到同一条棱，会自动与原方向交换，保证三轴不重复。
- **坐标原点**：默认晶胞顶点 (0,0,0)。把「3D 图交互操作」切到**设为坐标原点**后点任意原子，原点即迁移过去；此后所有弹窗里的坐标都按这个自定义坐标系显示。点「重置」恢复。

### 5. 原子库

- 内置 24 种元素（H、He、Li、Be、B、C、N、O、F、Na、Mg、Al、Si、P、S、Cl、K、Ca、Ti、Fe、Cu、Zn、Br、I、Cs），颜色取标准 CPK 配色，半径按元素周期律（真实原子半径 / 金属半径）排列。
- 也可以输入自定义名称 + 取色器选色后点「+」新建原子。
- 点击已添加的原子标签将其设为「当前选中」，供下面「快速添加位置」使用。

### 6. 快速添加位置

选中原子后一键放入：**顶点、体心、面心、棱心、四面体空隙、八面体空隙**，会自动补齐该位置的全部等效点。下方列表逐条显示，可单独删除。

### 7. 自定义分数坐标

- 输入 x / y / z 三个分量，支持小数（`0.25`）或分数（`1/4`）。
- 勾选「应用立方晶系对称性」会自动扩展成该坐标的整个等效点系；每种晶系用各自的对称操作集（立方 48、四方 8、六方 12、正交 8、单斜 4、三斜 1）。
- 允许输入晶胞外的坐标（如 `-0.1`、`1.2`），用于画边界补全的原子。

### 8. 3D 图交互操作

| 模式 | 行为 |
|---|---|
| **查看坐标**（默认） | 只弹信息，不改结构 |
| **替换原子** | 把点中的原子换成「目标原子」下拉框里选的那一种，颜色和半径同步更新 |
| **掺杂替换** | 同样是替换式掺杂，用于模拟取代 / 掺杂，位置不变 |
| **制造空穴** | 隐藏该原子（模拟空位） |
| **设为坐标原点** | 把原点迁移到该原子 |

要点：

- 点击处有多个原子重叠时，**所有模式**都会先弹出「选择要…的原子」列表（色球 + 名称 + 分数坐标 + 前 / 第 N 层），点哪条只对哪条生效，不会出现「看到 A、改的却是 B」。
- 修改**不施加对称性**——这正是做晶格缺陷、单点掺杂的正确方式。
- 修改按「原子位置」记录而不是按索引，重建晶胞后依然保留。

最后可点 **🔄 生成 / 更新晶胞** 手动重建；大部分改动（换类型、改参数、增删位置）会停止输入约 0.6 秒后自动重算。

## 右栏：3D 视图与投影图

### 3D 视图

- 左键拖动旋转、滚轮缩放、右键拖动平移。
- 点击原子弹出信息框：原子名、类型、分数坐标、笛卡尔坐标，若设了自定义原点还会同时显示自定义坐标系下的坐标。
- 边界上的原子会在外侧补全成完整球，便于观察整体堆积；补出来的球位于 0 / 1 的等价位置，界面会把它们视为**同一个格点**，替换 / 挖空会同时作用于该格点的所有副本。

### 投影图

五个视角按钮：

| 按钮 | 含义 | 3D 中的投影面 |
|---|---|---|
| 沿 z 轴看 | (001) | 贴在晶胞外侧 |
| 沿 x 轴看 | (100) | 贴在晶胞外侧 |
| 沿 y 轴看 | (010) | 贴在晶胞外侧 |
| 体对角线 | (111) | **不绘制**投影面，只画投影图 |
| 对角面 | (110) 等 | 位于晶胞**正中央**，沿对角面切开晶胞，并且比晶胞大 |

**对角面共 6 种**，选中「对角面」后用右侧下拉框切换：

| 选项 | 所含面对角线 |
|---|---|
| (110) | 含 x-y 面对角线 |
| (1-10) | 另一条 x-y 面对角线 |
| (101) | 含 x-z 面对角线 |
| (10-1) | 另一条 x-z 面对角线 |
| (011) | 含 y-z 面对角线 |
| (01-1) | 另一条 y-z 面对角线 |

投影规则：

- 原子按「前遮后」绘制：半径大的若在更前方会覆盖半径小的；反之形成**同心圆**。
- 点击投影图上的原子，会列出投影到该处的**全部**原子（按深度从前到后），每条带色球、名称、分数坐标（含自定义坐标系）与「最前 / 第 N 层」标记。
- 「显示晶胞外原子」开关（左栏「显示模式控制」里）控制投影图里是否画跑出晶胞框的原子（像石墨、冰这类层状结构边界补全后会露在外面）；3D 图中这些原子始终显示。

## 常见问题

**打开后 3D 区域空白？**
需要联网加载 three.js。若网络受限，按「快速开始」里的离线方案把库放到本地。

**换了晶胞类型图没变？**
现在所有类型切换都会自动重建；极端情况下点一次「🔄 生成 / 更新晶胞」。

**投影图点了没反应？**
投影数据随 3D 一起生成，先确认图已出现；若刚改过参数，等自动重算完成（约 0.6 s）。

**点原子老是点到被挡住的那个？**
重叠时一定会弹出候选列表，列表顶部就是视线最前面的原子，往下才是被挡住的。想改「看到的那个」就点第一条。

**为什么顶点原子替换后，另外 7 个角也变了？**
顶点、棱、面上的原子在空间里是**同一个格点**，只是边界补全画了多份。替换 / 挖空会作用到同一格点的全部副本，否则会出现「一个角是 Na、另一个角还是 Cl」的错误结构。若只想改一个位置，请用自定义分数坐标在晶胞内部添加原子后再编辑。

**想完全从零搭一个晶胞？**
类型选「自定义分数坐标」，在原子库添加原子、再用「自定义分数坐标」逐条输入位置（可配合对称性勾选）。

**画出来的球太大 / 太小？**
关掉「空间填充」用球棍模式；或把晶胞参数改成具体数字并选对单位。

## 技术细节

### 依赖

- [three.js](https://threejs.org/) **r128** 与其 `OrbitControls`，**已内嵌**在 `index.html` 开头（约 630 KB 压缩源码），运行时没有任何外部请求。
- 无框架、无构建步骤、无后端、无网络依赖；整个应用就是一个 `index.html`（约 3 700 行 / 730 KB）。

### 文件结构

```
Unit_Cell_Generator/
├─ index.html            # 唯一必需文件：内嵌 three.js + 样式 + 结构 + 应用脚本
└─ README.md             # 本文档
```

### 主要模块

| 位置 | 作用 |
|---|---|
| `state` | 全局状态：晶胞类型、参数、原子表、位置表、修改记录、坐标系、主题 |
| `ATOM_DB` | 24 种元素的 CPK 颜色与真实半径 |
| `PRESETS` | 21 种预设的分数坐标（`bondCut` 控制成键距离阈值） |
| `CELL_TYPE_SYSTEM` / `SYMMETRY_OPS` | 晶系归属与各晶系对称操作 |
| `cellGeometry()` | 由 a、b、c、α、β、γ 求基向量、8（六方 12）个顶点与全部棱 |
| `fracToCartGeo()` / `cartToFrac()` | 分数坐标 ↔ 笛卡尔坐标 |
| `resolveCellParams()` | 按晶系规整参数、校验角度合法性 |
| `generateCrystal()` | 主流程：参数 → 几何 → 原子 → 化学键 → 相机取景 |
| `drawCellFrame()` | 画晶胞棱（立方 12 条，六方 18 条） |
| `getProjectionFrame()` | 按视角算投影方向、平面位置、包围盒（3D 投影面与 2D 投影图共用） |
| `renderProjection()` | Canvas 2D 画投影：晶胞棱 + 按深度排序的径向渐变圆 |
| `handleProjectionClick()` | 投影图命中测试 + 重叠列表 |
| `visualRadius()` | 真实半径 → 场景单位，并按晶胞类型封顶，避免大离子糊住晶胞 |
| `computeWorldPerAngstrom()` | 字母参数 / 数字单位 → 世界单位换算 |

### 尺度换算

- 参数填字母时：`worldPerAngstrom = 晶胞体积立方根 / 该结构参考棱长`，按该结构的真实尺寸等比缩放原子。
- 参数填数字时：`worldPerAngstrom = 1 / UNIT_TO_ANGSTROM[单位]`，即按所选单位换算。
- 投影圆半径 = 原子世界半径 × 投影缩放比，保证 3D 与投影图视觉一致。

### 坐标系换算

自定义原点 `O` 与三根轴的单位向量 `ex, ey, ez`（由所选的晶胞棱方向得到）确定后，
原子笛卡尔坐标 `P` 的用户坐标 = `( (P−O)·ex, (P−O)·ey, (P−O)·ez )`。

### 浏览器支持

Chrome / Edge / Firefox / Safari 近三年版本；需要 WebGL 与 Canvas 2D。移动端可触摸旋转。
